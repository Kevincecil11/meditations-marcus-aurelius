# Meditations — Marcus Aurelius

An interactive, beautifully designed guide to **Marcus Aurelius' Meditations** — the complete text of all 12 books (George Long translation, 1862, public domain).

## Features

- **Complete text** of all 12 books, word for word
- **Book-by-book summaries** explaining the core themes
- **36 key quotes highlighted** with "In Plain English" explanations
- **Two reading modes**: Full Text or Key Quotes Only
- **Search** across all passages with highlighting
- **Bookmark** any passage to your saved collection
- **Daily reflection** — a random key quote each day
- **Expand/collapse** explanations for highlighted quotes
- **Progress bar** and book navigation
- **Fully responsive** — works on desktop, tablet, and mobile

## About the Translation

This uses the **George Long (1862)** translation, which is in the public domain. It's the most widely used classical English translation of the Meditations.

## About Marcus Aurelius

Marcus Aurelius (121–180 AD) was Roman Emperor from 161 to 180 AD, the last of the "Five Good Emperors." The Meditations were his private journal — never intended for publication — where he worked through Stoic philosophy to manage the pressures of ruling an empire. They remain one of the most practical guides to clear thinking and inner peace ever written.
